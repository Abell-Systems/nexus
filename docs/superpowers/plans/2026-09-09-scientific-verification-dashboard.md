# Scientific Verification Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a researcher-facing, self-contained Scientific Verification Dashboard in `frontend/` accessible at `#/scientific-verification`, presenting point-in-time empirical evidence, project context, and explicit epistemic boundaries to non-technical researchers (Lydia) without server infrastructure.

**Architecture:** Static SPA on GitHub Pages reading verified data from `project_status.json` via a strict contract hook, combined with manually versioned semantic framing in `scientific_context.json`. Slide-over drawer exposes raw cryptographic hashes and ADR links on demand. Secondary markdown report `SCIENTIFIC_VERIFICATION.md` generated by CI.

**Tech Stack:** React 19, TypeScript, Vitest, `@testing-library/react`, Tailwind CSS / CSS Modules, Python stdlib (for secondary report generator).

## Global Constraints

- **Single Source of Truth:** `project_status.json` is the sole authority for verified evidence. The UI never computes or overrides status checks.
- **Fail-Safe Invariant:** Missing or malformed `project_status.json` must render `VERIFICACIÓN NO DISPONIBLE`. Zero green fallbacks or optimistic passes.
- **Strict Epistemic Restraint:** The UI must never claim more than the evidence warrants (e.g. "Trazabilidad reproducible confirmada", NEVER "100% reproducible" or "modelo universalmente válido").
- **Point-in-Time Provenance:** Displays the exact dataset ID, evaluated commit SHA, and ISO timestamp. Never presents verification as an eternal, timeless property.
- **Zero Server Runtime:** Must function completely statically on GitHub Pages via hash routing (`#/scientific-verification`).

```typescript
import { describe, it, expect, vi, beforeEach } from "vitest";
import { useScientificVerification } from "../useScientificVerification";

describe("useScientificVerification", () => {
  beforeEach(() => {
    vi.restoreAllMocks();
  });

  it("handles missing project_status.json as unavailable without crashing", async () => {
    global.fetch = vi.fn().mockResolvedValue({
      ok: false,
      status: 404,
      json: async () => ({}),
    });
    const { result } = renderHook(() => useScientificVerification("/missing.json"));
    await waitFor(() => expect(result.current.state).toBe("unavailable"));
    expect(result.current.error).toContain("No se pudo cargar el reporte de verificación");
  });

  it("extracts 3 pillars when project_status is valid", async () => {

      schema_version: "1.0.0",
      commit_sha: "7928e22",
      evaluated_at: "2026-09-09T08:00:00Z",
      overall_status: "PASS",
      dimensions: {
        scientific_integrity: {
          status: "PASS",
          checks: [
            { name: "dataset_sha_sidecar", status: "PASS", detail: "ok" },
            { name: "temporal_policy_binding", status: "PASS", detail: "ok" },
            { name: "temporal_eligibility", status: "SKIPPED", detail: "3 exceptions under ADR-0018/ADR-0019" }
          ]
        }
      }
    };
    global.fetch = vi.fn().mockResolvedValue({
      ok: true,
      json: async () => mockStatus,
    });
    const { result } = renderHook(() => useScientificVerification("/project_status.json"));
    await waitFor(() => expect(result.current.state).toBe("verified"));
    expect(result.current.data?.provenance.commitSha).toBe("7928e22");
    expect(result.current.data?.protocolPillar.hasAcceptedExceptions).toBe(true);
  });
});
```

```typescript
// frontend/src/main/features/scientific-verification/__tests__/epistemicInvariants.test.tsx
import { render, screen } from "@testing-library/react";
import { describe, it, expect } from "vitest";
import { VerificationHero } from "../components/VerificationHero";
import { VerificationPillars } from "../components/VerificationPillars";

describe("Epistemic Invariants", () => {
  it("never asserts universal model efficacy when scientific integrity passes", () => {
    render(<VerificationHero state="verified" datasetId="pilot" commitSha="123456" evaluatedAt="2026-09-09" />);
    expect(screen.queryByText(/el modelo es universalmente válido/i)).toBeNull();
    expect(screen.queryByText(/100% reproducible/i)).toBeNull();
  });

  it("renders temporal eligibility exceptions explicitly as SKIPPED with ADR references, never as unconditioned PASS", () => {
    const mockPillars = {
      dataIntegrity: { status: "PASS", checks: [] },
      protocol: {
        status: "PASS",
        checks: [{ name: "temporal_eligibility", status: "SKIPPED", detail: "3 exceptions under ADR-0018/ADR-0019" }]
      },
      reproducibility: { status: "PASS", checks: [] }
    };
    render(<VerificationPillars pillars={mockPillars as any} />);
    expect(screen.getByText(/ADR-0018\/ADR-0019/i)).toBeInTheDocument();
    expect(screen.getByText(/3 excepciones/i)).toBeInTheDocument();
  });

  it("renders UNAVAILABLE and zero green elements when report is missing", () => {
    render(<VerificationHero state="unavailable" datasetId="unknown" commitSha="unknown" evaluatedAt="unknown" />);
    expect(screen.getByText(/VERIFICACIÓN NO DISPONIBLE/i)).toBeInTheDocument();
    expect(screen.queryByText(/VERIFICADO/i)).toBeNull();
  });
});
```
