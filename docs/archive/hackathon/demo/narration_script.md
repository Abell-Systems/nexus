## Full run-through (read straight, no cuts) — ~135 words, ~55s of speech

Patent research is broken. Here's the fix.

R&D teams face a real problem: industry tech calls point to urgent market
demand, but patent landscapes are dense, and nobody has time to check
whether a promising idea is already claimed. Abell Systems built an
autonomous agent that does that end to end — no human in the loop.

It starts from a real technology domain and pulls real patent data. It
clusters the landscape to find white space, then an Inventor agent proposes
a concrete, patentable candidate. But it doesn't stop there: a second
agent — the adversary — actively tries to kill its own invention, attacking
it against the same prior art. If it survives, it earned it.

And this isn't a mockup — it's live, on Cloud Run. Every surviving
opportunity comes with a score, a confidence level, and the exact prior art
it was tested against. Nothing is a black box.

Built with Google ADK and Gemini. Real research. Real evidence.
